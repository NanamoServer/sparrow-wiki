# 在线时间统计

原文：<https://nanamoserver.github.io/sparrow-wiki/zh-Hans/features/online-time>

模块 `online_time` · 配置文件 `features/online_time.yml`

统计玩家每天的在线时长，查看日活、新玩家和留存情况。挂机时间计入在线时长。统计从玩家进入游戏开始，持续到断开连接；启用前的历史在线时间不会补录。新玩家按 Sparrow 档案的首次登记时间识别，不以首次启用本模块的日期重新登记。

## 命令和权限

所有报表命令都需要在游戏内使用，默认权限均为 `sparrow.command.online_time.report`。

| 命令 | 用途 |
| - | - |
| `/online-time` | 打开每日活跃概览。 |
| `/online-time new [日期]` | 指定登记日的新玩家名单，默认今天；格式 `YYYY-MM-DD`。 |
| `/online-time retention` | 打开新玩家精确日留存表。 |
| `/online-time player <玩家>` | 打开玩家当前月份的在线记录。 |
| `/online-time calendar <玩家> [年月]` | 打开同一个在线记录页面，可指定 `YYYY-MM`。 |

例如 `/online-time new 2026-11-01`、`/online-time calendar Catnies 2026-10`。玩家参数支持已有档案的离线玩家。日期不能晚于今天；月份不能晚于当前月。命令配置项为 `online_time_report`。

## 统计时区

```yaml
time-zone: Asia/Shanghai
```

新生成的配置使用 `Asia/Shanghai`；删除此项或留空时使用系统时区。修改后必须重启服务器。群组中参与统计的服务器应使用相同的时区。

每天按该时区的自然日计算，本周从周一开始，本月从月初开始。跨午夜、跨月持续挂机的时长会分配到对应日期，不需要重新登录。修改时区不会重新划分已经记录的历史日期。

## 每日活跃概览

![每日活跃概览实机截图](https://nanamoserver.github.io/sparrow-wiki/zh-Hans/img/online-time/overview.png)

每页显示 14 个日期，按日期倒序排列，通过上一页、下一页、首页和末页浏览。

| 列 | 统计口径 |
| - | - |
| 日活 | 当天有正在线时长的不同玩家人数。 |
| 新登记 | 当天首次登记的玩家人数，与当天是否已有在线时长分开统计。 |
| 总时长 | 全部玩家当天在线时长之和。 |
| 人均 | 总时长除以日活人数；无人活跃时显示 `—`。 |

点击新登记人数进入对应日期的新玩家名单，页头的留存入口打开留存表。报表反映已保存的记录，在线玩家的新增时长通常每分钟保存一次，离服时也会保存；报表不是逐秒刷新。今天以 `*` 标记暂计数据。

## 新玩家名单

显示玩家名、登记时刻、首日时长及活跃天数。首日时长只计算登记当天；活跃天数按统计范围内有正在线时长的日期计数，不要求连续。

使用上一页、下一页、首页、末页浏览名单；前一天和后一天按钮切换登记日期。点击玩家名打开其在线记录。通过报表之间的链接进入页面时，可用返回按钮回到来源页。

## 玩家在线记录

![玩家在线记录实机截图](https://nanamoserver.github.io/sparrow-wiki/zh-Hans/img/online-time/player.png)

`player` 与 `calendar` 共用一个页面。顶部显示首次登记日期、所选月份的在线时长和活跃天数，以及累计在线时长和累计活跃天数。

逐日表每页 8 天，按日期正序显示。当天在线是该日时长；累计在线、累计活跃日从可展示记录的起点累计到该行日期，不只是当前页或当前月。没有在线时长的日期也会列出，今天带 `*`。

上一页、下一页在月内翻页；上月、下月切换到目标月的月初页；月初和回到今天提供快捷定位。未来日期不展示。

## 精确日留存

每页显示 14 个登记日期，列为 D1、D2、D3、D4、D5、D7、D14。登记当天是 D0。

**DN = 该批新玩家在登记后的第 N 个自然日有在线时长的人数 ÷ 该批登记人数。**

例如 11 月 1 日登记了 100 人，其中 20 人在 11 月 8 日活跃，则 D7 为 20%。只看指定日期，不要求连续上线，也不会把中间未上线的日期补为留存。因此 D3 可以高于 D2。

百分比按数值着色，悬停可查看观察日期和实际人数。今天的观察值带 `*`，未来日期、采集未覆盖完整的日期或没有登记人数时显示 `—`，悬停可查看原因。本页合计按每列符合条件的登记人数加权，排除当天尚未结束的观察值，不是简单平均各行百分比。点击登记日期可打开该批新玩家名单。

## PlaceholderAPI

安装 PlaceholderAPI 后可使用以下占位符，无需另外下载扩展：

| 周期 | 可读时长 | 完整秒数 |
| - | - | - |
| 今天 | `%sparrowtime_today%` | `%sparrowtime_today_seconds%` |
| 本周 | `%sparrowtime_week%` | `%sparrowtime_week_seconds%` |
| 本月 | `%sparrowtime_month%` | `%sparrowtime_month_seconds%` |
| 累计 | `%sparrowtime_total%` | `%sparrowtime_total_seconds%` |

Sparrow 自己的文本使用 `<papi:sparrowtime_today>` 这样的 MiniMessage 标签。占位符以调用它的插件提供的目标玩家为准。

本服在线玩家的值包含当前尚未保存的在线时长。离线玩家首次查询会等待记录读取完成，可能有短暂延迟。查询其他服务器上的在线玩家时，不保证实时更新；持续查询可能一直显示先前读取的值，直到玩家上下线。不要将它当作跨服实时计时器。模块停用或目标玩家资料尚未就绪时可能返回空文本。
