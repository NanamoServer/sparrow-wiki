---
title: ✨ 区域高亮
---

模块 `highlight` · 配置 `features/highlight.yml`

为指定玩家显示区域内的方块轮廓，不修改实际方块。省略目标时，向该世界的在线玩家显示。

| 命令 | 用途 | 默认权限 |
| --- | --- | --- |
| `/highlight [targets] [options]` | 显示区域方块轮廓。 | `sparrow.command.highlight` |

```text
/highlight @s --from 0 64 0 --to 5 68 5 --highlight-color green --highlight-duration 20
```

不填坐标可交互选点：左键记录自身位置，右键记录点击的方块，选两次即显示。再次执行无坐标命令可取消选点。

| 选项 | 用途 |
| --- | --- |
| `--from`、`--to` | 两端坐标，必须一起提供。 |
| `--world <world>` | 指定世界；控制台必填。 |
| `--highlight-duration <秒>` / `-d` | 持续 0–300 秒。 |
| `--highlight-color <颜色>` / `-c` | 颜色，如 green、red。 |
| `--solid-only` | 仅显示实体方块中暴露于空气等可穿过方块或选区边界的部分。 |
| `--silent` / `-s` | 隐藏命令反馈。 |

默认显示 30 秒、最多 32768 格，选点超时 30 秒。和平难度世界不支持此功能。
