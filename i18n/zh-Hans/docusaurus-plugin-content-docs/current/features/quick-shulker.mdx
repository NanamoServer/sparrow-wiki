---
title: 📦 快捷潜影盒
---

不需要放置潜影盒，就能直接存取其中的物品。默认情况下，手持潜影盒，**潜行并对着空气右键**即可打开。

## 使用方式

主手和副手都可以使用。两只手同时持有潜影盒时，优先打开主手中的潜影盒。右键方块不会触发快捷打开。

此功能没有独立的打开命令，也没有单独的使用权限节点。是否可用由功能开关、潜行要求和世界限制决定。

## 配置

~~~yaml title="features.yml · quick-shulker"
quick-shulker:
  enabled: true
  require-sneaking: true
  allow-offhand: true
  title: '<arg:hover_name>'
  disabled-worlds: []
~~~

| 配置 | 说明 |
| --- | --- |
| `enabled` | 是否启用。 |
| `require-sneaking` | 是否要求潜行；改为 `false` 后，直接对空气右键即可。 |
| `allow-offhand` | 是否允许打开副手潜影盒。 |
| `title` | 界面标题，`<arg:hover_name>` 显示当前潜影盒的物品名称。 |
| `disabled-worlds` | 禁用此功能的世界名称，空列表表示不限制。 |

例如 `disabled-worlds: [minigame]` 会在 `minigame` 世界停用快捷打开。
