---
title: 🔍 玩家巡查
---

模块 `patrol` · 配置 `features/patrol.yml`

依次传送到群组服玩家身边。省略目标时从可巡查玩家中轮流选择。

## 命令与权限速查

| 命令 | 用途 | 默认权限 |
| --- | --- | --- |
| `/patrol [targets]` | 轮流巡查玩家，支持跨服。 | `sparrow.command.patrol` |

### 附加权限

| 权限 | 用途 |
| --- | --- |
| `sparrow.bypass.patrol` | 不被巡查选中。 |

## 配置示例

```yaml
# 选择巡查目标时跳过旁观者
skip-spectators: true
```
