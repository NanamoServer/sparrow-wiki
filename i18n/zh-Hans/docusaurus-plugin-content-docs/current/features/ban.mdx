---
title: 🔨 封禁
---

模块 `ban` · 配置 `features/ban.yml`

跨服封禁账号、IP 或 IP 范围，并保留历史记录。

| 命令 | 用途 | 默认权限 |
| --- | --- | --- |
| `/ban <player\|player_ip\|ip> <target> [reason] [--time <duration>] [--force] [--silent]` | 封禁账号或 IP。 | `sparrow.command.ban` |
| `/unban <player\|player_ip\|ip> <target> [--silent]` | 按账号或 IP 解封。 | `sparrow.command.unban` |
| `/unban_id <id> [--silent]` | 按记录 ID 解封。 | `sparrow.command.unban_id` |
| `/ban_info <id>` | 查看封禁记录。 | `sparrow.command.ban_info` |
| `/ban_history <all\|player <player>\|ip <ip>> [options]` | 查询封禁历史。 | `sparrow.command.ban_history` |

```text
/ban player Steve griefing --time 7d
/ban player_ip Steve
/ban ip 192.0.2.* unwanted traffic
/ban_history player Steve --active
/unban_id 12
```

`player` 封禁账号；`player_ip` 封禁该玩家最后记录的 IP，不额外封禁账号；`ip` 直接指定地址或范围。省略 `--time` 为永久封禁，`--force` 替换同目标的有效封禁，`--silent` 隐藏通知与成功反馈。

历史查询支持 `--page <页码>`、`--active`、`--within <时长>`、`--operator <名称>`。`sparrow.notify.ban` 接收封禁与解封通知。

在 `reason-presets` 中配置常用原因，输入与预设名称完全相同时展开。通知音效使用 `notify-ban-sound`、`notify-unban-sound`。
