---
title: 🔑 命令与权限
---

`<参数>` 必填，`[参数]` 可省略。下表是默认入口与权限，短命令也可写为 `/sparrow <命令>` 或 `/spr <命令>`。修改 `commands.yml` 后需要重启。

`[.other]` 表示指定其他玩家的分支另需 `.other` 权限。实体选择器只选择本服目标；支持跨服的命令可直接填写其他子服的玩家名。

默认多词命令使用连字符，例如 `/set-home`，对应权限为 `sparrow.command.set_home`。

## 插件管理

| 命令 | 用途 | 默认权限 |
| --- | --- | --- |
| `/sparrow reload [--silent]` | 重载配置。 | `sparrow.command.admin.reload` |
| `/sparrow feature-list` | 玩家打开模块管理窗口。 | `sparrow.command.admin.feature` |
| `/sparrow feature-enable <feature>` | 立即启用模块，不保存开关。 | `sparrow.command.admin.feature` |
| `/sparrow feature-disable <feature>` | 立即停用模块，不保存开关。 | `sparrow.command.admin.feature` |

管理[死亡消息](./features/death-messages.mdx)时，模块名填写 `death_messages`。需要在重载或重启后保留模块开关时，请修改 `modules.yml`。

## 管理与玩家记录

| 命令 | 用途 | 默认权限 |
| --- | --- | --- |
| `/maintenance [true\|false] [--all] [--tag <tag>]` | 切换维护状态。 | `sparrow.command.maintenance` |
| `/max-players [amount]` | 查询或修改人数上限；-1 恢复原上限。 | `sparrow.command.max_players` |
| `/kick <targets> [reason] [--silent]` | 踢出玩家，支持跨服。 | `sparrow.command.kick` |
| `/ban <player\|player-ip\|ip> <target> [reason] [--time <duration>] [--force] [--silent]` | 封禁账号或 IP。 | `sparrow.command.ban` |
| `/unban <player\|player-ip\|ip> <target> [--silent]` | 按账号或 IP 解封。 | `sparrow.command.unban` |
| `/unban-id <id> [--silent]` | 按记录 ID 解封。 | `sparrow.command.unban_id` |
| `/ban-info <id>` | 玩家打开封禁详情。 | `sparrow.command.ban_info` |
| `/ban-history <all\|player <player>\|ip <ip>> [options]` | 玩家浏览封禁历史。 | `sparrow.command.ban_history` |
| `/player-info <name-or-uuid>` | 查看玩家资料及封禁状态。 | `sparrow.command.player_info` |
| `/player-uuid <name>` | 查询玩家 UUID。 | `sparrow.command.player_uuid` |
| `/name-history <name-or-uuid>` | 查询曾用名。 | `sparrow.command.name_history` |
| `/ip-history <player <name>\|uuid <uuid>\|ip <ip>>` | 查询玩家 IP 历史或某个 IP 的使用记录。 | `sparrow.command.ip_history` |

`/player-info`、`/name-history` 和 `/ip-history` 仅限玩家使用。在资料窗口中，按权限可查看曾用名、IP 和封禁记录，或传送到玩家退出时的位置。在 IP 历史窗口中点击地址可查看用过它的玩家。

## 补充用法

- `ban-history` 支持 `--active`、`--within <时长>`、`--operator <名称>`，在对话框中翻页。详见[封禁](./features/ban.mdx)。
- `rtp-range` 支持 `--center-x`、`--center-z`、`--min-y`、`--max-y`、`--silent`，详见[随机传送](./features/rtp.mdx)。
- `edit-home` 和 `edit-warp` 的 `rename`、`relocate` 分别需要在基础权限后追加 `.rename`、`.relocate`。编辑他人的家还需要 `.other`。
- 参见[高亮命令参数](./features/highlight.mdx)和[高亮 API](./api/highlight.mdx)。

消息与物品文本使用 MiniMessage。PlaceholderAPI 用 `<papi:占位符>` 或 `<papi:占位符:默认值>`；`item-name` 和 `custom-name` 可用 `--json` 输入 JSON。

### 物品描述

`/item-lore editor` 中每行对应一条描述。清空后保存可移除全部描述。命令行可用 `/item-lore edit --operation insert --lore <gold>宝藏` 追加一行。行号从 1 开始，只有 `insert` 可省略 `--line`。其他操作为 `edit`、`remove`、`up`、`down`。`insert` 和 `edit` 都需要通过 `--lore` 提供 MiniMessage 文本。控制台须用 `--player` 指定本服在线玩家，编辑他人需要 `sparrow.command.item_lore.other`。

## 其他权限

| 权限 | 用途 |
| --- | --- |
| `sparrow.bypass.maintenance` | 维护期间允许进入。 |
| 每种[电梯](./features/elevator.mdx)的 `use_permission` | 将配置的权限节点授予可以乘坐这类电梯的玩家。默认留空，所有人均可使用。 |
| `sparrow.bypass.player_limit` | 满员时允许进入。 |
| `sparrow.bypass.patrol` | 不被巡查选中。 |
| `sparrow.notify.ban` | 接收封禁与解封通知。 |
| `sparrow.bypass.tpa_cooldown` | 跳过请求间隔和拒绝后的等待。 |
| `sparrow.home.limit.<数量> / sparrow.home.limit.unlimited` | 覆盖家的数量限制。 |
| `sparrow.warp.use.<小写名称>` | 启用 permission-restrict 后允许使用对应传送点。 |
| `sparrow.back.staff / sparrow.back.vip` | Back 默认冷却与倒计时覆盖。 |
| `sparrow.deathback.staff / sparrow.deathback.vip` | DeathBack 默认冷却与倒计时覆盖。 |
| `sparrow.rtp.staff / sparrow.rtp.vip` | RTP 默认冷却与倒计时覆盖。 |
| `sparrow.tpa.staff / sparrow.tpa.vip` | TPA 默认传送冷却与倒计时覆盖。 |
| `sparrow.home.teleport.staff / sparrow.home.teleport.vip` | Home 默认冷却与倒计时覆盖。 |
| `sparrow.warp.teleport.staff / sparrow.warp.teleport.vip` | Warp 默认冷却与倒计时覆盖。 |
| `sparrow.spawn.staff` | Spawn 默认冷却与倒计时覆盖。 |

传送覆盖权限可在各功能的 `teleport-options.overrides` 中修改；RTP 区域权限由 `regions.<名称>.permission` 指定。
