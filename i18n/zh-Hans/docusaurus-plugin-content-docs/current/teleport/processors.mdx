---
title: 📍 落点规则
---

各命令的落点规则由功能确定。

| 功能 | 落点选择 |
| --- | --- |
| Spawn、Home、Warp、离线传送 | 使用保存或配置的坐标。 |
| TPA、巡查 | 使用目标玩家的位置。 |
| Back、DeathBack | 先检查原坐标，不安全时在水平 4 格、上下 8 格内寻找安全落点。 |
| RTP | 在指定区域内随机搜索；普通世界从地表向下找，下界等有顶维度在洞穴中找。 |
| World | 检查目的地，必要时在水平 8 格、上下 16 格内寻找落点。 |

安全搜索会检查边界、碰撞、脚底支撑和危险方块。Back、DeathBack 和 RTP 默认不接受水中、树叶上或下界顶层的落点；World 允许头部露出水面的浅水落点。

Back、DeathBack 和 World 的 `--unsafe` 允许搜索失败后使用原坐标。RTP 找不到安全位置时结束，不强行传送。

这些规则没有通用 YAML 处理器列表可修改。开发者可通过[传送 API](../api/teleport.mdx)组合搜索规则和处理器。
