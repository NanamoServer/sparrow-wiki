title: 🏁 Spawn
---

Module `spawn` · Configuration `features/spawn.yml`

Travel to the configured spawn, including on another backend. The command is unavailable until a destination is configured.

| Command | Purpose | Default permission |
| --- | --- | --- |
| `/spawn` | Travel to the configured spawn. | `sparrow.command.spawn` |

```yaml
destination:
  server: lobby
  world: world
  x: 0.5
  y: 64
  z: 0.5
  yaw: 0
  pitch: 0
teleport-options:
  cooldown: 5m
  warmup:
    duration: 0s
```

Configure the destination on each server and run `/spr reload`. Spawn uses the exact coordinates without a safe-location search.

Spawn supports cooldowns, warmups and permission overrides. Its warmup fields use hyphens, such as `cancel-on-move` and `cancel-on-damage`.
