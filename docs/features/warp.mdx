title: 📍 Warps
---

Module `warp` · Configuration `features/warp.yml`

Named destinations shared across your Sparrow servers.

| Command | Purpose | Default permission |
| --- | --- | --- |
| `/warp <name> [player]` | Travel to a warp, with support for cross-server players. | `sparrow.command.warp[.other]` |
| `/set_warp <name>` | Create a warp at your position. | `sparrow.command.set_warp` |
| `/del_warp <name>` | Delete a warp. | `sparrow.command.del_warp` |
| `/warp_list [page]` | List warps. | `sparrow.command.warp_list` |
| `/edit_warp <name> [rename <new_name>\|relocate]` | View, rename or relocate a warp. | `sparrow.command.edit_warp` |

```text
/set_warp market
/warp market
/edit_warp market relocate
```

Creation and relocation require a player. `/set_warp` does not overwrite an existing name. Names allow up to 32 characters; the default pattern accepts letters, digits, underscores and hyphens.

`rename` and `relocate` additionally require `sparrow.command.edit_warp.rename` and `sparrow.command.edit_warp.relocate`. Use `/del_warp` to delete a warp.

With `permission-restrict` enabled, viewing and using a warp requires `sparrow.warp.use.<lowercase-name>`. Management still uses command permissions. Configure cooldowns, warmups and arrival effects under `teleport-options`; see [Teleport options](../teleport/overview.mdx).
