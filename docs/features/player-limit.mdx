---
title: 👥 Player limit
---

Module `player_limit` · Configuration `features/player_limit.yml`

Change this server's player limit at runtime. Command changes are saved.

## Command and permission reference

| Command | Purpose | Default permission |
| --- | --- | --- |
| `/max-players [amount]` | View or change the player limit; -1 restores the original limit. | `sparrow.command.max_players` |

### Additional permissions

| Permission | Purpose |
| --- | --- |
| `sparrow.bypass.player_limit` | Allow entry when full. |

## Configuration example

```yaml
# Restore the previous limit; 0 sets a zero-player limit
max-players: -1
```

Disabling the module also restores the original limit.
