---
title: 📦 Quick shulker
---

Module `quick-shulker` · Configuration `features/quick-shulker.yml`

Hold a shulker box and sneak-right-click the air to open it. The off hand is supported; the main hand takes priority. No command or separate usage permission is required.

```yaml
require-sneaking: true
allow-offhand: true
title: '<arg:hover_name>'
disabled-worlds: []
```

`<arg:hover_name>` uses the box's item name. List restricted worlds in `disabled-worlds`.
