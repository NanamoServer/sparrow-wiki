---
title: 🧭 Teleport options
---

Cooldowns, warmups and arrival effects are configured in each feature's own file. For example, in `features/home.yml`:

```yaml
teleport-options:
  cooldown: 5m
  warmup:
    duration: 5s
    cancel_on_move: true
    cancel_on_damage: true
    display: action_bar
  invulnerability: 5s
  after_sound: entity.enderman.teleport
  overrides:
    - permission: sparrow.home.teleport.staff
      cooldown: 0s
      warmup:
        duration: 0s
    - permission: sparrow.home.teleport.vip
      cooldown: 1m
      warmup:
        duration: 3s
```

| Option | Meaning |
| --- | --- |
| `cooldown` | Cross-server cooldown starting after a successful teleport; `0s` disables it. |
| `warmup.duration` | Wait before departure; `0s` teleports immediately. |
| `cancel_on_move` / `cancel_on_damage` | Cancel the countdown after moving over half a block, changing worlds or taking damage. |
| `display` | `action_bar`, `title`, `boss_bar`, `chat` or `none`. |
| `invulnerability` | Protection duration after arrival. |
| `after_sound` | Arrival sound; an empty string or zero volume disables it. |
| `overrides` | Select the first matching traveler permission. Omitted options inherit; a supplied `warmup` replaces the entire option. |

Warmups also accept `boss_bar_color`, `boss_bar_overlay`, `warmup_sound` and `cancel_sound`. Sounds accept a name or `name,volume,pitch`, such as `entity.enderman.teleport,0.5,1`.

## Feature differences

| Feature | Configuration location |
| --- | --- |
| Home, Warp, TPA, RTP | `teleport-options` in their respective `features/<feature>.yml`. |
| Back, DeathBack | `back.teleport-options` and `deathback.teleport-options` in `features/back.yaml`. |
| Spawn | `teleport-options` in `features/spawn.yml`; supports only cooldowns, warmups and permission overrides. |

Spawn uses hyphenated warmup fields, such as `cancel-on-move` and `boss-bar-color`, and defaults to a `0s` warmup. The other features above default to a `5m` cooldown, `5s` warmup and `5s` arrival protection. Cooldowns are separate per feature, including separate Back and DeathBack cooldowns.
