✨ Highlight

Configure the command switch, permission and aliases in commands.yml. Plugins can also use the Highlight API.

Show block outlines to selected viewers without changing real blocks. Omitting targets shows them to online players in that world.

CommandPurposeDefault permission
/highlight [targets] [options]Highlight a region's blocks.sparrow.command.highlight
/highlight @s --from 0 64 0 --to 5 68 5 --highlight-color green --highlight-duration 20

Without coordinates, select two points interactively: left-click records your position; right-click records the clicked block. Run the command again without coordinates to cancel selection.

OptionPurpose
--from, --toEndpoints; provide both.
--world <world>World; required from console.
--highlight-duration <seconds> / -dDuration from 0 to 300 seconds.
--highlight-color <color> / -cA named color, such as green or red.
--solid-onlyShow solid blocks exposed to passable neighbors or the selection boundary.
--selection-timeout <seconds>Time allowed to select both points, at least 1 second.
--silent / -sHide command feedback.

Defaults are a green outline, 30 seconds of display, a 32768-block limit and a 30-second selection timeout. Peaceful worlds are not supported.
